# Security and privacy

This repository is a public demonstration project. Keep bot tokens, chat and
user identifiers, SQLite databases, logs, message exports, and local `.env`
files outside Git.

If a credential is ever committed, revoke it immediately and remove it from
the complete Git history. Deleting the file in a later commit is not enough.

Do not put personal data or secrets in public issues. Once the repository is
published, use a private GitHub security advisory or contact the maintainer
privately.
